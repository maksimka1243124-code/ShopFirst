# My First Project — Online Store

⚠️ **Note:** This is my first project. Code quality and architecture may not be perfect, but it's constantly improving.

## Description  
A simple online store (no real payments). Users can register, view products, manage a shopping cart, and place orders. Admin can manage products and orders.

## Features  
- Registration / Login (JWT)
- View products
- Shopping cart (add, remove, update quantity)
- Order placement
- Product CRUD (Admin)

## Future Plans  
- Refactoring to a cleaner architecture (controllers → services → repositories)
- Unit tests
- Docker
- CI/CD

## Tech stack  
- .NET 8, ASP.NET Core  
- EF Core
- JWT, FluentValidation  
- Middleware (added later)  
- DTO
